# HarpScore

跨平台的**布鲁斯口琴（十孔口琴）乐谱软件**——琴谱展示、管理与导出。开源，MIT 协议。

![License](https://img.shields.io/badge/license-MIT-blue)

## 功能

- **专业琴谱展示**：上行简谱（数字 + 八度点 + 升降号 + 附点 + 节奏下划线 + 延音线 + 歌词），下行口琴演奏标记（吹吸方向 + 孔号 + 压音级别 + 超吹 + 技巧），小节线 / 反复记号 / 双纵线完整刻画
- **吹吸配色**：`+N` 吹气（暖红）、`-N` 吸气（深蓝）、`'` 压音（每个符号半音）、`°` 超吹、`~` 颤音
- **曲谱管理**：内置曲谱 + 个人曲谱（浏览器本地持久化），搜索、查看、删除、JSON 导入
- **导出**：PNG（高清位图）、SVG（矢量）、打印 / PDF、JSON 源文件
- **可吹性分析**：按指定标准 Richter 调性自动标注孔位，统计音域、压音数量，超出当前口琴能力的音即时提示（不含 Low/High 特殊型号）
- **手机阅读**：按可用宽度自动重新分行，保留长音、多八度点和跨行延音；导出使用完整页面布局
- **跨平台**：纯 Web 应用，浏览器即开即用，桌面 / 手机 / 平板通用（PWA 友好）

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产出 dist/
npm run preview  # 预览构建结果
npm test         # 导入器自动化测试
npm run scores:validate # 校验全部内置谱
```

开发环境要求 Node.js 20.19+ 或 22.12+（Vite 8 要求）。

## 曲谱数据格式

曲谱为 JSON（见 `src/data/scores/*.json`）：既可导入包含 `lines` 的完整 HarpScore JSON，也可导入包含 `melody` 的旋律 DSL JSON。导入器会校验嵌套结构、规范化八度、避免 ID 覆盖，并重新推算口琴孔位。

批量制谱使用配套导入工具：`tools/import/*.json` 为旋律 DSL 输入（空格分词、`|` 小节线、`/` 八分、`//` 十六分、`'` 高音点、`,` 低音点、`#`/`b` 升降、`~` 延音、`=字` 歌词、`-` 延长一拍），运行 `npm run scores:build` 完成“深层校验 → 八度规范化 → 可吹性验证 → 孔位推算 → 写入内置曲谱 → 重建索引”全流程。

非原创内置谱优先以文字简谱或清晰数字简谱逐音核对，并记录 `sourceUrl`、`sourceFormat` 与 `sourceCheckedAt`；五线谱不作为图片识别输入。`npm run scores:validate` 会同时阻止节拍、可吹性或来源字段不完整的曲谱进入发布。

## 技术栈

Vite + React + TypeScript，乐谱为纯 SVG 渲染，无重型依赖。
