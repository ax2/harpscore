# HarpScore v0.2.0

本阶段将内置曲库从14项扩充至64项：60首歌曲、4首原创练习，并修复音高、时值、指法、导入和打印中的多项问题。

## 新功能与修复

- 逐首记录选定曲谱的来源、移调方式和核对范围；按传统曲与入门曲均衡扩充。最新加入《康定情歌》《一起来学唱》《苏武牧羊》《小蜜蜂》。
- 支持变拍、前倚音、带明确辅助音的波音、三十二分音符、显式弱起、自由延长、重音和保持音；保留跨小节/跨行同音延音。
- 修正标准Richter口琴的音高与孔位，明确低音压音及超吹提示；诊断位置与可选小节编号一致。
- 增加多条件曲库筛选、排序、收藏、个人库备份与预检恢复；修复存储并发、慢文件读取和键盘焦点问题。
- 手机按实际可用宽度重排，密集小节保留续行关系；PNG/SVG/JSON导出及A4分页打印同步。
- 内置谱的传输数据去重，保留完整音乐内容及公开JSON格式。
- 新增标签触发的GitHub Release工作流：Windows/Linux Node24验证通过后构建、打包并上传Web版本及SHA256校验文件。

## 下载和使用

下载 `harpscore-0.2.0-web.tar.gz` 与 `SHA256SUMS.txt`，解压后安装Node.js 24或更新版本，无需运行npm install。

- Windows：双击 `START.cmd`，在浏览器打开 `http://127.0.0.1:4178`。
- macOS/Linux：在解压目录运行 `node serve.mjs`，打开同一地址。
- 静态网站部署：上传包内 `dist/` 内容；不要直接双击其中的HTML。

Windows可用 `tar -xzf harpscore-0.2.0-web.tar.gz` 解压，`Get-FileHash -Algorithm SHA256 harpscore-0.2.0-web.tar.gz` 校验文件。此包是Web应用，不是Windows EXE。

个人曲谱和收藏保存在浏览器，绑定网站地址和端口。升级前导出个人库备份，升级后沿用原地址与浏览器；如改了地址，请从备份恢复。

## 验证范围

150项自动测试覆盖来源旋律对照、节拍/延音/孔位门禁、导入和存储、记号与打印布局、数据打包隔离及本地启动器。64项曲库验证和生产构建通过。Chromium/Firefox检查64曲的三种谱宽；新曲经过实际搜索、导出、手机及打印DOM检查。新两曲Chromium实际PDF分别2页和1页，组合标记经过导入、重载和导出验证。

当前没有音频播放。音乐核对针对注明的来源版本，尚未经过独立音乐专家、实体口琴、真实手机和打印机的验收；Firefox原生PDF与WebKit未验。不将自动测试声称为专业音乐审校，也不将体积减少声称为启动速度必然提高。
